# Alfie — Marketing Landing Page

The standalone marketing site for Alfie, financial intelligence infrastructure for the organizations that handle money.

This page previously lived inside the Renda landing site as its Alfie Platform page. It was moved here on 2026-11-15 so Alfie stands as its own product, and removed from the Renda site.

## Develop

```sh
npm install
npm run dev
```

## Deploy

GitHub Pages, via `.github/workflows/pages.yml`: every push to `main` builds with base `/Alfie-Marketing-Landing-Page/` and deploys automatically.

Live: https://alfie-ai-platforms.github.io/Alfie-Marketing-Landing-Page/
